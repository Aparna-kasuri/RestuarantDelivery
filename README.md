Restaurant Delivery Management System

A simple full-stack web application for managing restaurant customers, orders, delivery staff, and deliveries — built with a Java (com.sun.net.httpserver) backend, SQLite database, and a plain HTML/CSS/JavaScript frontend.

Features
Manage Customers (add, view, update, delete)
Manage Orders (add, view, update, delete)
Manage Delivery Staff (add, view, update, delete)
Manage Deliveries (link orders to staff, track delivery time/date)
Lightweight REST API served directly from Java's built-in HttpServer — no external frameworks required
SQLite database for persistent storage
Static frontend (HTML/CSS/JS) served from the same backend
Tech Stack
Backend: Java (com.sun.net.httpserver.HttpServer)
Database: SQLite (via sqlite-jdbc)
Frontend: HTML, CSS, JavaScript 
Prerequisites
Java JDK 11 or higher
sqlite-jdbc-3.51.3.0.jar
