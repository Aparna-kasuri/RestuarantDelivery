# Restaurant Delivery Management System

The **Restaurant Delivery Management System** is a simple full-stack web application developed to manage restaurant operations efficiently. It allows users to manage customers, food orders, delivery staff, and deliveries through an easy-to-use interface. The backend is built using **Java's built-in HttpServer**, while **SQLite** is used for storing data permanently. The frontend is developed using **HTML, CSS, and JavaScript**. The application provides RESTful APIs to perform CRUD (Create, Read, Update, Delete) operations on all modules. It supports adding, viewing, updating, and deleting customer, order, delivery staff, and delivery records. The system also allows assigning orders to delivery staff and tracking delivery details. Since it uses Java's built-in server, no external frameworks are required, making it lightweight and easy to deploy. This project demonstrates database connectivity, REST API development, and frontend-backend integration using core Java technologies.

## Tech Stack
- **Backend:** Java (HttpServer)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite (sqlite-jdbc)
- **API:** RESTful API

## Prerequisites
- Java JDK 11 or higher
- sqlite-jdbc-3.51.3.0.jar
